# Security Policy

## Supported Versions

Only the latest release receives security fixes.

## Reporting a Vulnerability

Please do not open a public issue. Report it privately from
[Security → Report a vulnerability](https://github.com/guccyon/cornix-layout/security/advisories/new).

---

## セキュリティポリシー

セキュリティの修正は最新のリリースにだけ入れます。
脆弱性を見つけたら公開の Issue にせず、
[Security → Report a vulnerability](https://github.com/guccyon/cornix-layout/security/advisories/new) から非公開で報告してください。
