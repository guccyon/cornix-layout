# ウインドウ配置ショートカット（Hyper キー化）

## 変更履歴

### 2026-10-12: ⌃⌥ から Hyper（⌃⌥⇧⌘）へ変更

| 用途 | Cornix の位置 | 変更前 | 変更後 | QMK キーコード |
| --- | --- | --- | --- | --- |
| 左半分 | レイヤー1 右手 row3 `left` | ⌃⌥← | ⌃⌥⇧⌘← | `HYPR(KC_LEFT)` |
| 右半分 | レイヤー1 右手 row3 `right` | ⌃⌥→ | ⌃⌥⇧⌘→ | `HYPR(KC_RIGHT)` |
| フィル（全画面） | レイヤー1 右手 row3 `down` | ⌃⌥Enter | ⌃⌥⇧⌘Enter | `HYPR(KC_ENTER)` |

- 設定ファイル: `config/layers/1_symbols.yml` に `Ctrl + Option + Shift + Command + Left` のように記述。
  コンパイラが4修飾の組み合わせを自動で `HYPR(kc)`（Vial キーコード `0x0F00 | kc`）に変換するので、
  1キーで4修飾＋キーを同時送出できる。
- 背景: macOS 標準のウインドウ配置はアプリのメニュー経由で動くため、⌃⌥←/→ を VSCode
  （cursorWordPartLeft/Right）、⌃⌥Enter を Ghostty が先に処理してしまい効かなかった。
  アプリ側の設定変更は復旧コストが高いので、どのアプリも使わない Hyper に寄せた。
- 別マシンの Rectangle も同じキーに揃え、Cornix のキーマップを共通化する。

## Mac 側の設定

### macOS 標準のウインドウ管理（このマシン）

1. システム設定 > キーボード > 「キーボードショートカット…」を開く。
2. 左の一覧から「ウインドウ」を選ぶ。
3. 次の3項目のショートカットをそれぞれ変更する。項目のショートカット欄をダブルクリックして
   入力待ちにし、**Cornix のレイヤー1でそのキーを押す**（手で4修飾を同時押しするより確実）。
   - 左（Left / 左半分）: Cornix の `←` 位置 → ⌃⌥⇧⌘← と表示されれば OK
   - 右（Right / 右半分）: Cornix の `→` 位置 → ⌃⌥⇧⌘→
   - フィル（Fill）: Cornix の `↓` 位置（Enter を送るキー）→ ⌃⌥⇧⌘↩
4. 古い ⌃⌥ の割り当てが残っていないこと、他の項目と重複の警告（黄色の三角）が出ていないことを確認する。
5. 任意のアプリのメニュー「ウインドウ > 移動とサイズ変更」を開き、左・右・フィルの横に
   新しいショートカットが表示されていれば反映済み。

「ウインドウ」項目が見つからない OS バージョンでは、「アプリのショートカット」で「すべてのアプリケーション」に
メニュー名（「左」「右」「フィル」。メニューに表示されている通りの名前）を指定して同じキーを登録する。

### Rectangle（別マシン）

1. メニューバーの Rectangle アイコン >「設定…」（Settings）を開く。
2. ショートカット一覧で次の3項目の記録欄をクリックし、Cornix のキーを押して上書きする。
   - Left Half（左半分）: ⌃⌥⇧⌘←
   - Right Half（右半分）: ⌃⌥⇧⌘→
   - Maximize（最大化）: ⌃⌥⇧⌘↩
3. macOS 標準のウインドウ管理側にも同じキーを割り当てていると二重に動くので、
   Rectangle を使うマシンでは標準側の割り当ては外しておく。
4. バックアップ: 設定画面の「一般」（General）タブ下部の「Export」で `RectangleConfig.json` を保存する。
   復元は同じ場所の「Import」から。保存先は dotfiles など同期される場所にしておくと別マシンへ持ち込みやすい。

## 動作確認と切り分け

### 動作確認

1. VSCode をアクティブにして Cornix で左半分・右半分・フィルを押し、ウインドウが配置されることを確認。
2. Ghostty でも同じ3キーを確認（以前効かなかったのはフィル）。
3. 念のため VSCode のエディタ上で ⌃⌥←/→ 本来のカーソル移動（cursorWordPartLeft/Right）も
   従来通り動くことを確認する。

### 効かなかったときの切り分け

1. **Cornix が正しいキーを送っているか**: `bin/cornix device diff` で差分 0 件か確認する。
   テキストエディタや「キーボードショートカット」の入力欄で Cornix のキーを押し、⌃⌥⇧⌘ 付きで認識されるかを見る。
2. **OS 側の登録が効いているか**: Finder やテキストエディットなど素のアプリで試す。ここで効かなければ
   システム設定（または Rectangle）の割り当てを見直す。「ウインドウ > 移動とサイズ変更」メニューに
   ショートカットが表示されているかも確認。
3. **アプリが横取りしているか**: 素のアプリでは効き、特定アプリだけ効かない場合はアプリ側のキーバインドを確認する。
   - VSCode: コマンドパレット「Preferences: Open Keyboard Shortcuts」で検索欄のキーボードアイコン
     （Record Keys）を押し、Cornix のキーを押して割り当てが無いか見る。
   - Ghostty: `ghostty +list-keybinds` で `ctrl+alt+shift+super+...` の割り当てが無いか確認する。
4. **他の常駐ツール**: Karabiner-Elements や Raycast / Alfred などのホットキーと被っていないか確認する。
